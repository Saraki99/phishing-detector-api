# PhishGuard AI - Frontend\n\n## Overview\n\nEnterprise-grade phishing detection platform built with Next.js 15, React, TypeScript, and Tailwind CSS.\n\n## Tech Stack\n\n- **Next.js 15** - React framework\n- **React 19** - UI library\n- **TypeScript** - Type safety\n- **Tailwind CSS** - Styling\n- **Framer Motion** - Animations\n- **Lucide Icons** - Icons\n- **Zustand** - State management\n- **Recharts** - Analytics charts\n\n## Getting Started\n\n### Prerequisites\n\n- Node.js 18+ or Bun\n- npm or yarn\n\n### Installation\n\n```bash\ncd frontend\nnpm install\n```\n\n### Environment Variables\n\nCreate `.env.local`:\n\n```bash\nNEXT_PUBLIC_API_URL=http://localhost:8000\n```\n\n### Development\n\n```bash\nnpm run dev\n```\n\nOpen [http://localhost:3000](http://localhost:3000)\n\n### Build\n\n```bash\nnpm run build\nnpm run start\n```\n\n## Features\n\n- ✨ Hero section with CTA\n- 🛡️ Features showcase\n- 🔍 URL scanner component\n- 📊 Analytics dashboard\n- 💬 Testimonials\n- 💰 Pricing plans\n- 🌓 Dark mode support\n- 📱 Mobile responsive\n- ♿ Accessibility compliant\n- ⚡ Optimized Core Web Vitals\n\n## Deployment\n\n### Vercel\n\n```bash\nnpm install -g vercel\nvercel\n```\n\n### Environment Variables (Production)\n\nSet in Vercel dashboard:\n- `NEXT_PUBLIC_API_URL` - Backend API URL\n\n## Project Structure\n\n```\nfrontend/\n├── public/           # Static assets\n├── src/\n│   ├── app/         # Next.js app router\n│   ├── components/  # React components\n│   ├── hooks/       # Custom hooks\n│   ├── store/       # Zustand stores\n│   └── app/\n│       ├── layout.tsx\n│       ├── page.tsx\n│       └── globals.css\n├── package.json\n├── tsconfig.json\n├── tailwind.config.js\n└── next.config.js\n```\n\n## Performance\n\n- Image optimization\n- Code splitting\n- CSS-in-JS\n- API route caching\n- Automatic static optimization\n\n## Security\n\n- Content Security Policy headers\n- X-Frame-Options protection\n- XSS Protection\n- HTTPS enforcement\n\n## License\n\nMIT\n
